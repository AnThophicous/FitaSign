# Segurança

O FitaSign 0.1.0 é uma beta local. Não exponha a ponte MCP em uma interface de rede pública. O token por execução e o diretório de dados pertencem ao usuário do sistema.

Para relatar uma falha, use o aviso privado de segurança do repositório no GitHub quando disponível. Não publique tokens, arquivos de conexão ou provas contendo projetos privados em uma issue pública.

As garantias e limites de IPC, armazenamento e MCP estão em `docs/architecture.md`. A beta não executa código dos documentos. O script Luau exportado deve ser revisado e integrado pelo desenvolvedor do jogo.
